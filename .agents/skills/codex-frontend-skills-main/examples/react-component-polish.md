# Example: React Component Polish

Use this when a component works but feels unfinished.

## Prompt

```text
Use the frontend React and design skills.

Polish this React component without changing its product meaning.

Focus on:
- accessible labels and focus states
- loading, disabled, empty, and error states
- stable button dimensions
- no layout shift on hover
- responsive behavior at 375px, 768px, 1024px, and 1440px
- project tokens instead of random colors
- restrained motion that respects prefers-reduced-motion

Follow the existing codebase style. Do not add a new UI library unless the
project already uses it or the benefit is clear.
```

## Expected Skills

- `frontend-react-ui`
- `frontend-design-core`
- `frontend-browser-qa`

## What Good Looks Like

- The component fits the existing app.
- Buttons and forms behave like production controls.
- Motion supports comprehension instead of showing off.
- The final answer includes verification notes.
