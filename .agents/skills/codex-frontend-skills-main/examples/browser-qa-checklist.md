# Example: Browser QA Checklist

Use this after frontend changes.

## Prompt

```text
Use the frontend browser QA skill.

Open the local app and verify the changed screen.

Check:
- desktop and mobile screenshots
- console errors
- network failures
- blank canvases or charts
- text overlap and overflow
- keyboard focus visibility
- loading, empty, error, and disabled states
- reduced motion behavior when relevant

Do not mark the work complete until verification evidence matches the request.
```

## Expected Skills

- `frontend-browser-qa`
- `frontend-design-core`

## What Good Looks Like

- QA is tied to the user-facing workflow.
- Screenshots or browser observations support the conclusion.
- Remaining risk is called out clearly.
