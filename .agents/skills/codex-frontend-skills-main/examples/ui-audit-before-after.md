# Example: UI Audit Before And After

Use this when the user asks whether a screen is good enough.

## Prompt

```text
Use the frontend strategy, UI/UX, and browser QA skills.

Audit this screen as if it were going into production.

Find issues in:
- information hierarchy
- interaction states
- accessibility and keyboard flow
- responsive layout
- text overflow
- chart choice and data explanation
- performance risk
- visual consistency

Return findings first, ordered by severity. Then propose a concise before/after
plan and implement only the high-impact changes.
```

## Expected Skills

- `frontend-strategy-review`
- `frontend-ui-ux-pro`
- `frontend-browser-qa`

## What Good Looks Like

- Findings are specific and actionable.
- The after state has fewer concepts competing for attention.
- The screen is easier to scan and easier to trust.
