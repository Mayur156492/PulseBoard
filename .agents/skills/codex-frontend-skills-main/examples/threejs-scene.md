# Example: Three.js Scene

Use this when you want a real interactive scene instead of a blank canvas or
static decorative block.

## Prompt

```text
Use the Three.js and browser QA skills.

Build an interactive Three.js scene for this product page.

Requirements:
- full-bleed or unframed primary scene
- nonblank canvas on first load
- responsive framing on desktop and mobile
- clear camera, lights, controls, and animation loop
- no layout overlap with UI
- graceful reduced-motion behavior
- verify with browser screenshots and canvas-pixel checks

Explain the scene architecture before implementation and list the checks after.
```

## Expected Skills

- `frontend-3d-motion`
- `frontend-browser-qa`
- `frontend-design-core`

## What Good Looks Like

- The object or scene is visible immediately.
- Camera and controls are intentional.
- Mobile view is framed, not cropped.
- The canvas is verified rather than assumed.
