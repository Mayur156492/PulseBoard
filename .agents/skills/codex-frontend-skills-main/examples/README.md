# Examples

These examples show what the frontend skills pack can make an agent do.

They are not just prompts. Each example demonstrates a capability: design
reasoning, UI feature coverage, implementation guidance, browser QA, or senior
review behavior.

## What A Good Demo Should Show

- The agent chooses a product pattern before coding.
- UI controls include real states: loading, disabled, error, empty, focus,
  hover, active, and responsive.
- Charts and dashboards explain decisions, not just data.
- Browser QA catches visual and runtime problems.
- The final answer includes evidence and remaining risk.
